# Nova tarefa

Pasta livre para anexar os arquivos da próxima tarefa: planilhas, PDFs, apresentações,
prints, o que for.

## Como subir os arquivos

Pelo botão **Add file · Upload files** direto nesta pasta, na branch `entregas-candidatos`.
Link direto:

https://github.com/wallaceuiad12/Kiro/upload/entregas-candidatos/nova-tarefa

Pode arrastar vários arquivos de uma vez. Depois de subir, me avise o que é para eu fazer
com eles.

## Observações

- Se a tarefa precisar de uma pasta por pessoa ou por item, como foi em
  `entregas-candidatos`, eu crio as subpastas numeradas.
- Se preferir outro nome para esta pasta, digo o nome e eu renomeio.
- O `.gitkeep` existe só para o Git versionar a pasta vazia. Pode apagar quando quiser.
