# prints

Pasta destinada a prints (capturas de tela) do projeto.

## Como usar

Coloque as imagens aqui, de preferência com nomes descritivos:

```
prints/
├── 01-tela-login.png
├── 02-dashboard.png
└── 03-erro-validacao.png
```

Formatos sugeridos: `.png`, `.jpg`, `.gif`, `.webp`.

Para exibir um print em qualquer arquivo Markdown do repositório:

```markdown
![Tela de login](prints/01-tela-login.png)
```

O arquivo `.gitkeep` existe apenas para que o Git mantenha a pasta versionada
mesmo quando ela estiver vazia — pode ser removido depois que houver imagens aqui.
