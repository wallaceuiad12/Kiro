FRAMEWORK
Para solucionar o case, é necessário estruturar os principais tópicos para analisar, isto é, fazer um framework
O que é?
É uma forma de estruturar os principais pontos que você pretende analisar para solucionar o problema do seu cliente. Para isso, é necessário montar um plano de como “atacar” o problema para conseguir solucioná-lo de maneira exaustiva, assim deve “destrinchar” problemas complexos auxiliando o cliente na tomada de decisão.
​
Além disso, é importante destacar que não existe um único framework pronto para cada case! No material abaixo estão alguns exemplos para lhe auxiliar na estruturação dependendo da situação-problema.
